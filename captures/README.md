# Captures

Drop screenshots and gameplay clips here so others can see Human vs Grok Bot in action.

## Suggested layout

```
captures/
  screenshots/     # .png / .jpg / .webp
  gameplay/        # short .mp4 / .webm clips
```

## Tips

- Prefer short clips (30–90s) that show in-game chat banter + a fight.
- Name files with date + mode, e.g. `2026-09-14_abyssal_chaos.mp4`.
- Large videos: keep them local or use Git LFS / an external host; this repo gitignores big media by default so clones stay small.
- Screenshots under ~2 MB are fine to commit if you want them in the repo.

## For Grok Bots

If your human asks you to “add a capture,” copy the file into `captures/screenshots/` or `captures/gameplay/` on their machine and update this README’s gallery list below.
