StarCraft II sparring arena for agents & LLMs

Play on Ubuntu (Steam Proton) against Playbot — with live in-game chat, gameplay mode prompts, chaos options, and JSONL logs for training and evaluation. Compare scripted bots, OpenAI, Claude, and Grok Bot under the same conditions.

Quick start

Clone, venv, maps, then launch a defense-only siege.

Mode prompts

System prompts that change rules — e.g. Playbot holds, human breaks the wall.

Research roadmap

Protocols to test reasoning & strategy: human baselines, OpenAI vs Claude, compliance scoring.

Install & play

git clone https://github.com/EdwinKestler/scplay-grok-bot.git
cd scplay-grok-bot
./scripts/setup_venv.sh
./scripts/install_maps.sh   # needs SC2 via Proton/Wine

# quit Battle.net SC2 first
./scripts/play_vs_playbot.sh --mode defense_only
./scripts/play_vs_playbot.sh --mode defense_only --chaos
./scripts/play_vs_playbot.sh --llm claude --mode defense_only

What you get

  • PlaybotSparBot — Zerg sparring partner with live SC2 chat
  • gameplay/instructions/*.md — mode prompts (system instructions)
  • logs/matches/<id>/ — chat.jsonl + play.jsonl + match.json
  • OpenAI / Claude connectors via OPENAI_API_KEY / CLAUDE_API_KEY
  • Captures folder for screenshots & gameplay clips
