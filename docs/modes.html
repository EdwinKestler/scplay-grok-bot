Scenario control

Change the rules. Keep the match honest.

Each gameplay mode is a portable Markdown system prompt paired with a bot behavior. Use them to create repeatable challenges without burying the rules in code.

Mode library

Two starting conditions.

The YAML frontmatter gives each mode an identity and selects a matching code path. The Markdown body is the human-readable instruction contract.

MODE / defense_only

Break the wall

Playbot fortifies its territory. The human takes the initiative and attempts to breach the defense.

behavior: defense_only
defense_only.md 
---
id: defense_only
title: Defense only (siege / break the wall)
behavior: defense_only
---

## Roles
- Playbot (Zerg): Defense only. Do not attack the human's base.
- Human: Play offensively. Break the wall and destroy hatcheries.

## Playbot rules
1. Fortify main/natural (spines, queens, lings).
2. Never send a proactive attack to the enemy start.
3. When enemies enter your territory, counter locally, then return.
4. Expand only to stabilize eco if needed.
5. Banter like a wall — dare the attacker in.

## Win conditions
- Playbot: crush the siege or stall the assault.
- Human: breach and kill bases.

Launch controls

Choose the pressure.

Add --chaos for free resources, instant builds, and unlocked tech—or attach an LLM coach to the same scenario.

Standard ./scripts/play_vs_playbot.sh --mode defense_only
Chaos ./scripts/play_vs_playbot.sh --mode defense_only --chaos
LLM coach ./scripts/play_vs_playbot.sh --llm openai --mode defense_only
