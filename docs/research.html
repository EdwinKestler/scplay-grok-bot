Research questions

What are we measuring?

Game outcomes matter, but they are only one signal. SCPlay also captures whether a model follows constraints, adapts coherently, and aligns its language with its actions.

Instruction following

Does the agent honor mode constraints, such as never leaving base during defense_only?

Tactical adaptation

How quickly and effectively does the defense react when a human push changes composition or timing?

Strategic coherence

Do economy, army, expansion, and technology choices support a recognizable plan?

Language ↔ action

Does the live chat describe the situation and decisions reflected in the match event log?

Cross-model behavior

What changes when the same micro bot is paired with different LLM coaches or agent workflows?

Comparison protocols

Control the variables.

Each protocol fixes the scenario and changes one dimension at a time, keeping comparisons easier to interpret.

A

Human vs AI

Fix the map and mode. Rotate scripted, OpenAI-coached, Claude-coached, and Grok Bot conditions. Score with the shared rubric plus human ratings.

B

OpenAI vs Claude

Keep the micro bot constant and change only --llm. This isolates coach language in v1 and coach decisions in v2.

C

Agent vs agent

Build toward bot-vs-bot and desktop-agent ladders that use the same instruction packs, telemetry, and scoring contract.

Scoring contract

A compact v1 rubric.

Every axis is scored from 0–2 and tied to a concrete log source, keeping the judgment reviewable after the match ends.
