Research roadmap

Test LLM and agent reasoning & strategy in StarCraft II under fixed mode prompts — human baselines, OpenAI vs Claude, compliance scoring. Canonical markdown: RESEARCH_ROADMAP.md.

Questions

  • Instruction following (e.g. never leave base in defense_only)
  • Tactical adaptation to human pushes
  • Strategic coherence (eco / army / tech)
  • Language ↔ action alignment (chat vs logs)
  • Cross-model: OpenAI vs Claude vs Grok Bot vs scripted

Comparison protocols

A. Human vs AI

Fix mode/map; rotate scripted, OpenAI coach, Claude coach, Grok Bot. Score with rubric + human ratings.

B. OpenAI vs Claude

Same micro bot; only --llm differs. Isolates coach language (v1) and decisions (v2).

C. Agent vs agent

Future: bot-vs-bot and desktop-agent ladder with shared instruction packs.
